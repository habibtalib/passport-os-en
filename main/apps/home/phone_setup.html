AI VoicePC voice input

Connect the device and your PC to the same Wi-Fi. Download the full PC package, install the virtual sound card and WeChat IME (any voice IME with a hotkey also works), then start the voice forwarder.

On the PC, pick CABLE Output as the input device; set the forwarder output to CABLE Input. Keep the IME hotkey the same as the forwarder. On the device, hold Up to talk and release to finish; Down sends Enter.

Color pocket cardsUp to 6

Store up to 6 cards or QR codes. On the home screen press Up to open, Up/Down to page, OK to go back. A 3:4 ratio is recommended; leave a white margin around QR codes.

In the file picker, long-press an image to enter multi-select, then tick the others and confirm. JPEG, PNG or WebP images are accepted.

Use the photo library instead

If Photos only allows one image, use the multi-select file entry above; you can save the images to the phone's Files first. Opening http://192.168.4.1 in the system browser avoids limits of some in-app browsers.

Each image is scaled to 240 × 320 and compressed; max 24 KB each, 144 KB for 6. Replace, remove and reorder are saved on "Save and finish".

Muse voice assistantOptional

You need your own Muse account, the phone app and a Gadget SDK Token. After saving, open Muse on the device, then pair from the phone Muse app via "Settings > Devices > Developer mode > Add device". When pairing, pick the Wi-Fi the device is currently on.

Request an SDK Token at the official Muse device site gadgets.muse.ai. Prepare it before joining the device hotspot.

Muse project and full setup guide · Needs Internet to view. Muse needs no virtual sound card or WeChat IME.

Reading Muse settings from the device…

The PC and device must be on the same LAN, and the proxy must allow LAN connections. While using the PC proxy, keep the PC and proxy software running. Clear the IP and save to switch back to a direct connection; existing pairing is kept.

Use only your own Token and never share it. Changing the Token requires pairing again. Configured over the device hotspot; the page never shows the saved key.

The Token and PC proxy settings are stored on this device and survive restarts. You can also save them together with "Save and finish" below.

Clausium (Claude sessions)Optional

Shows which Claude Code sessions need you, from the Clausium app on your Mac, and chimes when one does. On the Mac open Clausium Settings > Devices > Passport, turn it on, then copy the address and token here. The Mac and the device must be on the same Wi-Fi.

Open this section to read the saved settings.

Clear the address and save to turn Clausium off. The page never shows the saved token. Sound alerts can be turned off in Settings > Clausium Alerts.
